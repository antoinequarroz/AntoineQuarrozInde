Un devis dans un courriel, une maquette dans un dossier partagé, une validation dans un autre fil : le problème n’est pas toujours l’absence d’un outil.

Avant de construire un espace client, je commence par cartographier le parcours :

- quel document doit être retrouvé ;
- qui doit agir ;
- quelle version fait foi ;
- quelle est la prochaine action ;
- quels droits chaque rôle doit avoir.

Un exemple fictif dans mon nouvel article montre aussi pourquoi une validation dans une interface ne doit pas être présentée comme une signature électronique qualifiée.

Le bon espace client est parfois un simple dossier bien structuré. Parfois, il faut suivre des statuts, des rôles et des validations. La décision dépend du parcours réel, pas du nombre de fonctionnalités disponibles.
