Le danger quand on remplace Excel, ce n’est pas seulement de perdre une ligne.

C’est de perdre la règle qui allait avec.

Une cellule orange peut vouloir dire « rappeler le client ». Un numéro commençant par zéro peut être un identifiant. Une formule peut cacher une décision métier.

Importer les valeurs ne suffit donc pas.

Avant la bascule, je cadrerais trois choses :
• ce que l’équipe doit pouvoir faire le lendemain ;
• quel outil fait foi pendant les tests ;
• comment revenir en arrière sans perdre les nouvelles saisies.

Dans l’article du jour, je propose une méthode avec un exemple fictif d’interventions : règles de reprise, contrôles, pilote et bascule.
