# AQ-052 — Recherche : import CAMT.053

## Résultat attendu

Ajouter le relevé XML ISO 20022 CAMT.053 comme seconde source du rapprochement bancaire AQ-051, sans créer un autre flux comptable et sans confirmation automatique.

## Preuves du dépôt

- `app/components/admin/BankReconciliationPanel.vue` garde déjà le fichier local, affiche les propositions et transmet uniquement la ligne confirmée.
- `shared/utils/bankReconciliation.ts` normalise les transactions, calcule une identité stable et refuse les mouvements anonymes.
- `server/api/admin/payment-reconciliation.post.ts` recalcule l'empreinte côté serveur ; `record_invoice_payment_atomic` verrouille le solde dans `20260810221013_add_bank_import_fingerprint.sql`.
- Les tests purs vivent dans `tests/bank-reconciliation.test.ts` et le parcours authentifié dans `e2e/payment-operations.spec.ts`.

## Intégration et sécurité

Le parseur doit reconnaître `BkToCstmrStmt`, extraire uniquement les crédits comptabilisés, préférer `AcctSvcrRef`, `EndToEndId` ou `TxId`, puis réutiliser `BankTransaction`. L'XML reste dans le navigateur. Aucun DTD, entité externe, HTML brut ou écriture ne doit être exécuté. Les débits, montants invalides, devises invalides et opérations sans identité stable restent rejetés.

## Limites et tests

V1 limitée à CAMT.053 XML courant, sans ZIP, connexion bancaire, pain.002 ou écriture en masse. Tester namespaces, crédits/débits, lots `NtryDtls/TxDtls`, identité stable, doublon et mobile.
