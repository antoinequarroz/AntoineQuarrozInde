# Files d'exécution

Une file contient les sujets validés. Un item passe de `[ ]` à `[x]` après publication et vérification publique. Chaque cycle contrôle d'abord le blog et le sitemap afin d'éviter les doublons.

Depuis le 3 novembre 2026, la rubrique active est `actualites-2026-11.md`, puis ses prolongements datés selon `.codex/geo/news-policy.json` : une brève IA/tech un jour sur deux dès le 4 novembre, weekends compris. La sélection d’une annonce récente vérifiée est autorisée dans ce cadre ; les libellés privés des créneaux ne sont pas des titres publics. Un jour intercalaire sans article est normal. Ne pas prendre le premier ancien item ouvert sans contrôle de sa date.
